# CSV Visual Editor

CSV Visual Editor is a planned Notepad++ plugin for viewing and editing CSV files through a graphical, spreadsheet-like table.

## Project goal

The plugin will turn the active CSV document into a real row-and-column interface inside Notepad++, rather than limiting CSV work to syntax highlighting or aligned text.

## Planned first milestone

- 64-bit Notepad++ plugin for Windows
- C# and Windows Forms
- `DataGridView`-based visual table
- dockable plugin panel
- comma, semicolon, and tab delimiter handling
- quoted-field-aware CSV parsing
- read-only visual table MVP before safe two-way editing

## Status

The project is in its initial bootstrap phase. Source code and build instructions will be added after the technical baseline has been validated.
